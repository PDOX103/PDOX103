## Upload

1. Create or open the public repository `PDOX103/PDOX103`.
2. Upload every file and folder from this package to the repository root.
3. Commit to the `main` branch.
4. Open **Repository Settings → Actions → General**.
5. Under **Workflow permissions**, select **Read and write permissions** and save.
6. Open the **Actions** tab and manually run:
   - `Generate Snake Animation`
   - `Generate Projects Panel`

The snake and projects images will remain broken until their first successful workflows create the `output` and `projects` branches.
