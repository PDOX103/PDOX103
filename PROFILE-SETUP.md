## Upload

Copy every file and folder in this package into the public repository `PDOX103/PDOX103` and commit to `main`.

## Required repository permission

Open **Repository Settings → Actions → General → Workflow permissions** and select **Read and write permissions**. Without this, neither the `output` snake branch nor the `projects` branch can be created.

Then manually run:

- **Generate Snake Animation**
- **Generate Projects Panel**

The README images will look broken until those branches exist.

## Statistics cards

The README uses the public `github-readme-stats.vercel.app` endpoint so it renders immediately. For a reliable profile, fork `anuraghazra/github-readme-stats`, deploy it on Vercel, add your private token as `PAT_1`, and replace the public host in `README.md` with your own Vercel host. Never put the token in the repository or in chat.

## Portrait limitation

The video/reference banner contains another person's portrait. I did not copy that portrait into your profile. The supplied banner uses an abstract head-and-shoulders placeholder with the same dither, shimmer, dissolve, and three-shape morph system.

To make the portrait genuinely yours, use a sharp 1000 px+ head-and-shoulders photo with a flat background and run:

```bash
pip install pillow numpy scipy
python .github/scripts/generate_banner.py --photo your-photo.jpg
```

That regenerates both `dark.svg` and `light.svg` from your photograph.

## Projects

`projects.json` currently contains the profile repository itself because no list of your other repositories was included in the uploaded profile archive. Add real repositories using the same fields:

```json
{
  "name": "Project name",
  "repo": "PDOX103/repository-name",
  "logo": "project-logo.png",
  "description": "One accurate sentence",
  "tags": ["React", "Node.js", "MongoDB"]
}
```

Put the logo inside `logos/`. The workflow fetches stars, language percentages, and last-update times automatically.
